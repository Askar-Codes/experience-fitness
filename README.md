# Experience Fitness — Website Project

This is a trimester project for the Introduction to Web Technologies course. The site is built for Experience Fitness, a real gym in Astana.

## About the project

Experience Fitness offers martial arts, yoga, pilates, stretching, personal training, and more. This website introduces the club, shows membership pricing, lets visitors register, and lets them book a trial session.

Assignment 1 covered the HTML structure. Assignment 2 added CSS styling: colors, layout, flexbox, and grid. No JavaScript yet.

## Files

- index.html — home page with pricing and contacts
- registration.html — account registration form
- booking.html — trial session details and booking form
- colophon.html — how the site was made and validated
- css/base.css — shared styles: colors, fonts, header, nav, footer
- css/askar.css — personal styles for registration.html and booking.html
- images/ — photos used on the site
- tag-checklist — HTML tag checklist
- css-checklist — CSS selector checklist
- report.pdf — Task A and Task B reports for both assignments
- ai-log — notes on how AI was used during this project

## How to view the site

No server or installation needed. Just open index.html directly in a browser, and use the navigation menu to move between pages.

## Validation

Every page was checked with the W3C Markup Validation Service, and the CSS was checked with the W3C CSS Validator.
